# AU StudentSphere
### University Student Profile Management System

**Africa University**

## About the Project

AU StudentSphere is a University Student Profile Management System designed to provide a centralised platform for managing student information and academic profiles at Africa University.

The system aims to simplify student information management, improve access to student records, and provide an organised way for authorised university personnel to manage student profiles.

## Project Objectives

- Provide a centralised student profile management platform.
- Allow students to access and manage their personal information.
- Enable administrators to manage student records.
- Improve the accuracy and organisation of student information.
- Provide secure user authentication and role-based access.

## Main System Features

The planned features include:

- Student registration and login.
- Secure authentication.
- Student profile creation and management.
- Student information viewing and updating.
- Administrator dashboard.
- Student record management.
- Search and filtering of student profiles.
- Role-based access control.

*Note: Features will be implemented progressively during development.*

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/AU-StudentSphere.git
```

### 2. Navigate into the project

```bash
cd AU-StudentSphere
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

Once the application has been implemented:

```bash
python app.py
```
